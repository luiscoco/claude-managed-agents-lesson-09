# Visual continuity

The app preserves the earlier lessons’ astronaut mascot, pale blue background, white rounded panels, navy headings, blue actions, orange callouts, numbered flow and four activity tabs. Comfortable/larger text settings and keyboard tab navigation remain available.

All 19 API/configuration cards contain expandable colored TypeScript. Current and historical text render as sanitized rich text with colored fenced code; IDs and hashes use highlighted JSON. Native SVG architecture and swimlane diagrams scroll inside their regions on small screens.

Captures: desktop.png, mobile.png, runtime-policy.png, api-and-configuration.png, how-it-works.png, uml-architecture.png, uml-workflow.png and quiz.png. To reproduce, run a production preview and `node scripts/capture-previews.mjs`. PREVIEW_URL can select a temporary port.
